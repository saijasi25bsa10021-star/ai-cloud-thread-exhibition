How Detection Works
01
Feature extraction
Every log is enriched with hour-of-day, encoded action/country/user, and a rolling 10-minute failed-attempt count per IP.
02
Isolation Forest scoring
An unsupervised Isolation Forest (100 trees, 8% contamination) flags behavior that deviates from the learned baseline.
03
Deterministic rule pass
Three hard rules run alongside the model: brute-force velocity, geo + high-risk-action combinations, and logins from untrusted regions.
04
Narrative & recommendation
Each flagged event gets a plain-language reason and a severity-matched remediation checklist for the analyst.
